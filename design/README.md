# Drift 设计稿

八块板子，覆盖桌面 / 移动的主界面、空状态、配对流程、设备命名，以及交互规则与动效规范。每块板同时产出浅色与深色两个文件。

## 目录结构

```
design/
  *.svg                 ← 浅色成品
  *.dark.svg            ← 深色成品
  build.py              ← 从 src/ 展开生成上面两套
  src/
    tokens.json         ← 配色的唯一来源，每个 token 是 {light, dark}
    dark-literals.json  ← 没被 token 化的一次性色值的深色映射
    icons.svg           ← 图标的唯一来源
    boards/*.svg        ← 模板，唯一应该手动编辑的地方
```

**成品文件是生成物，不要直接改。** 改 `src/boards/` 里的模板，然后：

```bash
python design/build.py          # 重新生成 design/*.svg 与 design/*.dark.svg
python design/build.py --check  # CI 用：成品过期则退出码非 0
```

## 模板里的两种简写

| 写法 | 展开为 |
|---|---|
| `{{ink}}` | 当前主题下 `tokens.json` 里对应的色值 |
| `<!-- @icons -->` | `icons.svg` 里的整套 `<symbol>` |

构建时会校验：每个 `{{...}}` 都能解析、每个 `<use href="#…">` 都有对应 id、输出是合法 XML。展开成字面量是有意为之——SVG 里的 CSS 自定义属性在 librsvg、Inkscape 和部分 Figma 导入路径下不可靠，成品必须能独立渲染。

注意 `{{...}}` 只在属性值和 CSS 里使用，不要写进文案文本。

## 配色

每个 token 是一对 `{light, dark}`。深色值不是浅色值的机械反相：深底上纯饱和色会「发光」，所以强调色、成功色、危险色都降了饱和度并提了亮度。

| 角色 | token | 浅色 | 深色 | 浅色对比度 | 深色对比度 |
|---|---|---|---|---|---|
| 主文字 | `ink` | `#202331` | `#F1F4FA` | 15.6:1 | 15.6:1 |
| 正文 | `body` | `#3A4155` | `#D2D9E6` | 10.1:1 | 12.2:1 |
| 次级 | `muted` | `#5A6276` | `#A6AEBF` | 6.1:1 | 7.7:1 |
| 辅助 / 说明 | `faint` | `#6A7284` | `#8B93A6` | 4.8:1 | 5.6:1 |
| 禁用 | `disabled` | `#7C8496` | `#6B7385` | 3.8:1 | 3.6:1 |
| 图标 | `icon` | `#5F6678` | `#9BA5B8` | 5.9:1 | — |
| 主题色 | `accent` | `#6D64F6` | `#8E86FF` | — | 5.8:1 |
| 增量 / 待更新 | `delta` | `#9A520C` | `#F6B866` | 6.1:1 | 9.1:1 |
| 卡片 | `surface` | `#FFFFFF` | `#171B24` | — | — |
| 画布 | `canvas` | `#FBFCFE` | `#0A0C10` | — | — |

白底对比度按 `#FFFFFF` 计算；深色按卡片 `#171B24` 计算。文字一律不低于 4.5:1，深色版最低是 `faint` 的 5.6:1。

`disabled` 与纯装饰描边（分隔线、滚动条、项目符号）不承载信息，允许低于该阈值；但**任何作为唯一识别线索的描边**（如拖放区的虚线框）必须 ≥3:1，浅色为 `#8578EA`。

### 深色模式的两个坑

1. **白色有两种角色。** 卡片底色和紫底上的白字都是 `#FFFFFF`，整表反相会把按钮文字变成深色。所以拆成 `surface`（会变深）和 `on-accent`（恒为 `#FFFFFF`）。新增界面时，凡是叠在 `accent` / `success` / `danger` 实色上的文字和图标，一律用 `on-accent`。
2. **模板里还有一次性色值。** 没进 token 的淡紫、浅绿等，深色映射写在 `src/dark-literals.json`，只在构建深色时套用。加新颜色时优先加 token；确实只用一次的，记得同步补一条映射，否则深色下会闪出一块白。

## 图标

`src/icons.svg` 里是 26 个 24×24 描边图标，统一 `stroke-width` 1.7 / 2.2，用 `currentColor` 描边，调用处 `color` 控制颜色：

```svg
<use href="#i-file" x="125" y="163" width="22" height="22" color="{{accent}}"/>
```

移动端早期那套 `m-*` 图标与 `i-*` 画法完全相同，已合并，模板里统一引用 `i-*`。

## 排版下限

- 移动板正文 ≥ 10px，说明文字 ≥ 9.5px
- 规范板（1200 宽）说明文字 ≥ 9.5px
- 缩放使用 `transform="scale()"` 的嵌套内容，按**缩放后的实际字号**判断，不是源码字号

## 主界面的交互约定

主界面（桌面 `drift-main-desktop` / 移动 `drift-main-mobile`）用漂浮球体代替设备列表，改设计时守这几条：

- **没有发送键。** 输入框有内容，球体才浮出来；清空输入球体收起。
- **单击球体即发送，不做划过多选。** 设备多时拖空白处平移、滚轮/双指缩放，被窗口裁掉的球体露在边缘作为提示，右上角小地图标出当前视口。
- **状态只画在环上**：紫＝传输中（带百分比）、橙虚线＝内容改过、点按只补发差异、绿＝已同步、灰部分环＝已暂停；无环＝待发。
- **diff 只属于设备。** 输入框永远只显示正文和光标，不做高亮、不加徽章。
- **「+ 添加设备」是画布上的一颗虚线球**，配对完成后新设备直接落在画布上。

命名规则见 `drift-devices`：自己的名字在配对时广播给对方，别人的名字只改本地显示；列表里写「名字 → 型号」，两者一致时只显示一次。
